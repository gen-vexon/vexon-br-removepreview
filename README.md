# PDFプレビュー文字削除ツール

GitHub Pages向けの静的Webアプリです。Chrome / Edgeなどのブラウザ内でのみPDFを編集し、PDFをサーバーへアップロードしません。

## 公開方法

1. GitHubに新規公開リポジトリ（例 `preview-check-web`）を作成します。
2. `index.html` と `.nojekyll` をリポジトリのルートへアップロードします。
3. GitHubの `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → `main` / `(root)` → `Save`。
4. 数分後、表示されたPagesのURLにアクセスします。

## 対応範囲と注意事項

- 添付されたサンプルPDFに含まれる `Q q 1 0 0 1 0 0 cm /Fx1 Do Q` という単独の透かし描画ストリームを対象とします。
- その他の透かしや別構造のPDFは変更しない安全側の仕様です。
- PDFの通常の文字や請求額は変更しません。処理後は必ずPDFを開き内容を確認してください。
- PDF編集ライブラリ `pdf-lib@1.17.1` をCDNから読み込むため、初回表示時にネット接続が必要です。PDFデータをCDNへ送る処理はありません。
- 機密情報のあるサンプルPDFや実際の請求書をリポジトリにアップロードしないでください。
- 第三者の署名・証明書・改ざん検出情報など、PDFの署名に影響する可能性があります。署名付きPDFには使用しないでください。
